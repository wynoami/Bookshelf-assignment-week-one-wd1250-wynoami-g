## Grading Rubric

Use the percentages to distribute the total points for the assignment.

-   **User Interface (10%)**: The application uses a user interface that interacts with the classes as denoted in the requirements.
-   **Bookshelf class (15%)**: The application declares the `Bookshelf` class and meets the requirements denoted in the description.
-   **Book class (15%)**: The application declares the `Book` class and meets the requirements denoted in the description.
-   **FictionBook class (10%)**: The application declares the `FictionBook` class and meets the requirements denoted in the description.
-   **NonFictionBook class (10%)**: The application declares the `NonFictionBook` class and meets the requirements denoted in the description.
-   **Application Runs Without Errors (10%)**: The application runs without unexpected crashes or exceptions.
-   **Correct output (20%)**: The application matches the suggested output exactly.
-   **Readability (10%)**: The learner demonstrates well-organized, easy-to-read code that uses white space, well-named variables, and indentation appropriately.
